# Gate 1 decision (approved by Ricardo, 2026-06-05) — HYBRID

This is the APPROVED aesthetic direction. Build on this only.

- **Mode:** Dark. Near-black navy/slate background (approx #0B0F1A base, #111726 panels).
- **Accent:** Teal / mint (approx #2DD4BF primary, #5EEAD4 light). One confident accent; use sparingly for emphasis, links, key CTAs.
- **Neutrals:** Cool grays for text (#E5E7EB headings, #9CA3AF body on dark).
- **Logo:** NEW mark from scratch (do NOT copy D1/D2/D3). Deliver as clean SVG, plus a paired wordmark "The AI Builder". Must read as build + AI, work at 24px favicon size, and have a mono version for light backgrounds. Teal-on-dark primary.
- **Hero:** A realistic, high-quality generated image (gpt-image-2, describe-the-look, NO baked-in text, NO artist names), dark and teal-lit, modern AI-builder workspace energy. The new logo + headline are overlaid in code on top of the image (not generated into it).
- **Typography:** Dark-mode pairing, chosen by the designer. Suggested lanes: a strong geometric/grotesk sans for headings (e.g. Space Grotesk / Geist) + clean sans body (e.g. Inter); a tasteful serif-display heading is acceptable if it stays premium. Load via next/font.
- **Feel:** modern, technical, premium AI-builder-for-hire. High contrast, generous whitespace, subtle motion. Not generic AI-slop.
